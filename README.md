# Lead Intelligence — Android MVP

A synthetic-data Android prototype for an oriented lead intelligence application.

## Included
- Kotlin + Jetpack Compose
- Dashboard with priority/high/total lead counts
- Lead search and minimum-score filter
- Lead cards with opportunity score
- Lead detail screen
- Explainable lead signals
- Contact / Schedule / Dismiss UI placeholders

## Important
This prototype uses synthetic data only. Do not connect real LIC customer/policy data until an authorized backend, identity/access controls, consent/purpose controls, audit logging, and applicable privacy/security reviews are in place.

## Run
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Run on an Android emulator/device (Android 8.0 / API 26 or newer).
